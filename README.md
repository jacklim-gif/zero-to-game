# 从零到游戏 Zero to Game

在一个模拟的游戏编辑器里（界面仿照 Unity），跟着教练一步一步学做游戏。给完全没做过游戏的新手。

不用先装 Unity，也不会把项目弄坏。打开 app，选一章，界面左边的教练会告诉你下一步点哪里、拖什么、改哪个数字。做对了，清单会自动打勾。

## 下载和运行

### 方法一：下载安装包（推荐给普通玩家）

到本仓库右边的 **Releases**，下载对应系统的文件：

| 系统 | 下载哪个 |
| --- | --- |
| Windows | `Zero to Game Setup x.x.x.exe`（安装版），或 `Zero to Game x.x.x.exe`（免安装，双击直接开） |
| macOS | `Zero to Game-x.x.x.dmg` |
| Linux | `Zero to Game-x.x.x.AppImage` |

Windows 第一次打开时，如果出现「Windows 已保护你的电脑」，点「更多信息」，再点「仍要运行」。这是因为安装包没有付费签名，不是病毒。macOS 同理：右键点 app，选「打开」。

### 方法二：从源码运行（给想改内容的人）

先安装 [Node.js](https://nodejs.org)（选 LTS 版本），然后在这个文件夹里打开终端：

```bash
npm install     # 第一次运行，下载依赖
npm start       # 打开 app
```

自己打包安装包：

```bash
npm run dist:win     # Windows，产出在 dist 文件夹
npm run dist:mac     # macOS（需要在 Mac 上运行）
npm run dist:linux   # Linux
```

## 现在有什么

**第 0 章：Unity 入门**，共 13 步，约 30 分钟。界面有中文和英文两种，主页右上角可以切换。教练会用发亮的边框、箭头和拖动动画告诉你下一步点哪里、拖什么。

1. 认识五个窗口：Hierarchy、Scene、Game、Inspector、Project
2. 创建一个方块
3. 改名并放好位置
4. 移动、旋转、缩放（W、E、R）
5. 做地板
6. 新建 Material
7. 上色并拖到物体上
8. 认识 Prefab
9. 第一段 C# 脚本（可以点每一行看解释）
10. 调整摄像机
11. 点 Play，用 WASD 走动
12. 加 Rigidbody（刚体），走出地板会掉下去
13. 保存场景

模拟器也会重现新手常犯的错：脚本名字和 class 不一致会在 Console 报红字；Play 模式下的修改停止后会还原；没加 Rigidbody 的方块走出地板会浮在空中；没保存的场景名字后面有 `*`。

**第 1 章：恐怖游戏**，共 18 步，约 60 分钟。开场只有一块地板，你自己搭出一条 L 形的黑暗走廊：

- 第 1–2 步：用方块做墙，Ctrl+D 复制，放进场景里的蓝色框
- 第 3–5 步：第一人称玩家：胶囊、角色控制器、摄像机当眼睛，写 FirstPersonMove 脚本（填空）
- 第 6–8 步：关掉天空和环境光，做手电筒（聚光灯）和会闪的灯泡（点光源）
- 第 9–10 步：脚步声和越走越近越大声的环境音（3D 声音）
- 第 11 步：出口的门和触发区：走到门前，门升起来
- 第 12–14 步：会追你的怪物（NavMesh），被抓到显示 GAME OVER，逃出去显示 YOU ESCAPED
- 第 15–17 步：美化：暗色材质、雾、后期处理（暗角、胶片颗粒、色彩调整），可以用对比滑块看前后差别
- 第 18 步：保存，从头玩一遍

**第 1 章下篇：恐怖游戏进阶**，共 14 步，约 45 分钟。接着第 1 章做好的走廊：

- 第 1–4 步：把门放进「门轴」，用动画窗口录制开门动画（关键帧），修好「一直重复」（Loop Time），再用 Animator 让门先关着，收到 Open 才打开
- 第 5–7 步：互动系统：看着东西屏幕会提示「按 F」，捡起地上的手电筒
- 第 8–9 步：钥匙和锁着的门：没钥匙时提示锁着，有钥匙才播放开门动画
- 第 10–13 步：Jumpscare：藏起来的鬼、触发区、尖叫声、镜头抖动和红光（协程）
- 第 14 步：放出怪物，完整玩一遍

学完一章之后：

- **章末小测验**：6 道选择题，检查你记住了没有。
- **找 Bug 挑战**（每章一个）：给你一个坏掉的场景，自己找出 4 个问题修好。
- **自由模式**：没有教练，自己随便做。
- **导出到真 Unity**：把你写的脚本打包成 zip，里面附一张「在真 Unity 里怎么做」的清单。

编辑器里还有：

- **美化工具**：前后对比滑块（灰盒 vs 上色后）、调色盘（选一个主色，自动配色）、素材库（树、石头、木箱等 10 个装饰品）、摆放检查（提示「太整齐」「空角落」）、截图对比。
- **游戏系统**：UI（文字、图片、滑条、按钮）、饥饿/口渴条、昼夜循环、存档读档（PlayerPrefs）、物品数据。
- **其他**：撤销/重做、复制粘贴、按住 Ctrl 吸附网格、父子关系、碰撞体、触发器、第一人称移动、怪物追人（NavMesh）、点光源和聚光灯、灯光窗口（天空盒、环境光、雾）、后期处理、声音（音频源、3D 声音）、动画窗口（录制关键帧）和 Animator 窗口（状态、参数、过渡）、物体开关（SetActive）。
- **设置**（右上角齿轮）：语言、字体大小、提示方式、检查更新。按 `?` 看快捷键。

提示是分级的：先只有发亮的边框；卡住了点「给我提示」看文字，再点「指给我看」才出现箭头和「帮我做这一步」。不想等可以在设置里改成一直显示箭头。

```
app/index.html          页面结构
app/styles.css          样式
app/i18n.js             界面文字（中文 / English）
app/chapters/ch0.js     第 0 章：教练步骤、找 Bug 挑战、小测验
app/chapters/ch1.js     第 1 章（恐怖游戏）
app/chapters/ch1b.js    第 1 章下篇（互动、动画、Jumpscare）
app/scripts.js          内置脚本模板：第一人称移动、怪物追人、生存数值、昼夜、存档、物品
app/props.js            素材库的装饰品（用基本形状拼的，不用下载）
app/audio.js            声音（用代码合成的脚步声、环境音、怪物低吼、尖叫）
app/vendor/three.js     Three.js（3D 画面，已打包，不用上网）
app/editor.js           虚拟编辑器：3D 视图、拖放、物理、教练提示
prototypes/             渲染效果 demo（npm run demo）
main.js                 桌面 app 入口（Electron）
preload.js              给页面用的少量桌面功能：版本号、字体大小、检查更新
build/icon.png          app 图标
scripts/smoke.js        冒烟测试：打开 app 截图，npm run smoke
.github/workflows/      推送 v 开头的 tag 时自动打包三个系统的安装包
docs/                   截图
```

### 怎么加一章或改步骤

步骤写在 `app/chapters/ch0.js`、`ch1.js` 里的 `STEPS` 数组。文字都写成 `{zh: '中文', en: 'English'}`。每一步有：

- `title`：标题
- `body`：说明文字
- `conds`：打勾清单，每项是「文字 + 检查函数」，函数返回 true 就自动打勾
- `hint`：提示
- `auto`：「帮我做这一步」按钮要做的事
- `glow`：要发亮提示的界面区域
- `point`：箭头指向哪里，或者演示从哪里拖到哪里

界面上的文字（按钮、菜单、窗口名字）在 `app/i18n.js`。

## 发布新版本

```bash
git tag v0.1.0
git push origin v0.1.0
```

GitHub Actions 会自动在 Windows、macOS、Linux 上打包，并把安装包放到 Releases。
